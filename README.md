# Diplom_2: API Stellar Burgers

Java 11, Maven, JUnit 4, REST Assured, Allure.

Тела запросов задаются моделями `UserRequest`, `LoginRequest`, `OrderRequest`
и сериализуются Jackson. Шаги отмечены `@Step`; AspectJ подключён в Maven Surefire.
При `null` поле модели не отправляется, пустая строка или список сохраняются в JSON.
В моделях используются Lombok `@Data` и `@AllArgsConstructor`. HTTP-коды заданы
константами `HttpStatus`. Позитивный вход проверяется отдельно от трёх
параметризованных негативных вариантов.

```sh
mvn clean test
mvn allure:report
```

По умолчанию используется альтернативный учебный стенд
`https://qa-stellarburgers.education-services.ru`.
Другой адрес стенда можно передать через `-Dbase.url=https://...`.
Ожидание соединения и ответа ограничено свойством `-Dapi.timeout.ms=10000`.

Область проверок:

- регистрация нового и повторного пользователя;
- отсутствие и пустое значение каждого обязательного поля;
- вход с корректными данными, неверной почтой, неверным паролем и обоими неверными полями;
- создание заказа с авторизацией и без неё, с ингредиентами, пустым массивом,
  отсутствующим полем и неверным хешем.

Каждый тест создаёт собственные данные. Созданные тестовые пользователи удаляются
через API после теста. Список ингредиентов загружается с сервера, идентификаторы
не зашиты в код. Сетевые ошибки и ошибки подготовки данных не превращаются в PASSED.

Для двух сценариев использованы уточнения эксперта курса:

- Неверный хеш ингредиента: ожидается 400 и `success: false`.
  Уточнение от 12.10.2026 исправляет код 500, указанный на стр. 1 PDF.
- Заказ без авторизации: ожидается 200, `success: true` и положительный номер
  заказа. В ответе от 26.10.2026 эксперт подтвердила, что ревьюеры принимают
  этот вариант. Ограничение на стр. 5 PDF подразумевает отказ, поэтому
  выбранное ожидание основано на уточнении, а не на исходном тексте PDF.

Оба ожидания проверяются строго: альтернативные коды в тестах не допускаются.

## Сохранённый отчёт

В `allure-results/` сохранены результаты прогона 29.10.2026 — все 17 тестов.
Непустые пароли и токены в HTTP-вложениях скрыты; пустой пароль сохранён как `""`. Для просмотра без повторного запуска
тестов выполните из корня проекта:

```sh
mvn allure:serve -Dallure.results.directory="${PWD}/allure-results"
```

Чтобы только сформировать HTML, замените `allure:serve` на `allure:report`.
