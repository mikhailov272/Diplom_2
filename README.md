# Diplom_2: API Stellar Burgers

Java 11, Maven, JUnit 4, REST Assured, Allure.

```sh
mvn clean test
mvn allure:report
```

Другой адрес стенда можно передать через `-Dbase.url=https://...`.
Ожидание соединения и ответа ограничено свойством `-Dapi.timeout.ms=10000`.

Область проверок:

- регистрация нового и повторного пользователя;
- отсутствие и пустое значение каждого обязательного поля;
- вход с корректными данными, неверной почтой, неверным паролем и обоими неверными полями;
- создание заказа с авторизацией и без неё, с ингредиентами, пустым массивом,
  отсутствующим полем и неверным хешем.

Каждый тест создаёт собственные данные. Созданные тестовые пользователи удаляются
через API после теста. Список ингредиентов загружается с сервера, идентификаторы
не зашиты в код. Сетевые ошибки и ошибки подготовки данных не превращаются в PASSED.

По документации API (стр. 5) заказы доступны только авторизованным пользователям:
в тесте без авторизации ожидается 401. Если сервер создаёт такой заказ, тест должен
показать расхождение, а ожидаемый результат требует согласования с требованиями.
Для неверного хеша ожидается указанный в документации код 500.
